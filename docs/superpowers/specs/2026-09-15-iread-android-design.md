# iRead Android 本地小说阅读器设计说明

## 1. 项目目标

iRead 是一款仅面向 Android 的本地小说阅读应用。第一版专注于 TXT 与 EPUB 文件的离线导入、整理和阅读，不依赖账号或网络服务。

第一版应用名称为“iRead”，应用包名为 `com.iread.novel`。最低支持 Android 8.0（API 26）；编译和目标版本使用开发环境中可用的最新稳定 Android SDK。

## 2. 第一版范围

### 包含

- 书架：展示多本本地书籍，每本书显示封面、书名、作者和未读章节数。
- 书籍菜单：书架每本书右侧提供紧凑三点按钮，可编辑书名和作者，也可删除书籍。
- 导入：在设置页中支持选择一个或多个 TXT、EPUB 文件，以及扫描用户选择的文件夹。
- 阅读：支持左右分页和上下滚动两种阅读方式。
- 阅读设置：字号、行距、暖纸黄、雾霭蓝、深夜黑三种主题。
- 目录：根据解析后的章节显示目录并跳转。
- 进度：自动保存每本书的章节、页内位置和阅读模式。
- 书签：可在当前阅读位置添加或取消书签。
- 本地持久化：书籍、进度、书签和偏好在应用重启后保留。

### 不包含

- 登录、云同步、在线书城、搜索网络书源、广告、付费系统、社交功能。
- iOS 版本、听书、PDF/MOBI/AZW3 支持。
- 对原始文件的删除或修改。

## 3. 已确认的视觉与交互

### 书架

- 使用清新、克制的浅绿色视觉语言，保留淡绿色光晕、简化植物线稿和艺术化默认封面。
- 顶部标题为“我的书架”。右上角仅显示一个接近 iOS 导航栏风格的细线齿轮图标，不显示“设置”文字；可点击区域至少为 44×44 dp。
- 不显示“书架 / 最近阅读 / 设置”底部导航栏。
- 书籍行只显示：封面、书名、作者、未读章节数和右侧三点按钮；不显示“更新到哪一章”。
- 三点菜单包含“编辑书籍信息”和“删除本书”。删除前必须二次确认。

### 设置

- 第一组为“本地书库”：导入文件、扫描文件夹。
- 第二组为“阅读偏好”：默认主题、默认阅读方式、字号与行距。
- 设置页采用简单列表，不引入卡片堆叠或额外装饰模块。

### 阅读页

- 默认主题为暖纸黄，另提供雾霭蓝和深夜黑。
- 页面中心区域用于呼出或隐藏工具栏；左右区域在分页模式下用于上一页和下一页。
- 工具栏包含目录、书签、字号、阅读方式和主题入口。
- 阅读正文以中文长篇阅读为中心，标题、段落缩进、行距和页边距优先保证舒适度。

## 4. 技术方案

### 平台与界面

- Kotlin + Jetpack Compose。
- 单 Activity，使用 Compose Navigation 管理书架、设置和阅读页面。
- Material 组件只用于基础交互与无障碍能力，颜色、间距、图标和排版按当前原型定制，不直接套用默认 Material 风格。
- 采用 edge-to-edge 布局，并正确避让系统状态栏与导航栏。

### 代码组织

第一版保持单 `app` 模块，按职责划分包，避免过早拆成多个 Gradle 模块：

- `ui/shelf`：书架列表、书籍菜单、编辑和删除对话框。
- `ui/settings`：导入入口和阅读默认偏好。
- `ui/reader`：正文、目录、工具栏、分页与滚动模式。
- `domain/model`：Book、Chapter、ReadingProgress、Bookmark、ReaderPreferences。
- `domain/usecase`：导入、解析、删除、保存进度和计算未读数。
- `data/db`：Room 数据库及 DAO。
- `data/files`：应用私有文件、解析缓存和原文件信息。
- `data/parser`：TXT 与 EPUB 解析器，通过统一 `BookParser` 接口暴露结果。
- `data/preferences`：DataStore 阅读偏好。

界面层只接收状态并发送用户事件。ViewModel 调用用例；用例通过仓库读写数据库、文件和偏好。解析器与界面解耦，后续增加格式时不需要修改阅读器主体。

## 5. 数据设计

### Book

- 唯一 ID
- 书名、作者
- 格式：TXT 或 EPUB
- 应用私有副本路径
- 原始文件 URI（仅用于来源提示，不作为运行依赖）
- 封面路径或生成封面参数
- 导入时间、最近阅读时间
- 总章节数

### Chapter

- 唯一 ID、所属书籍 ID
- 顺序、标题
- 正文缓存位置或 EPUB 内容引用
- 字符数

### ReadingProgress

- 书籍 ID
- 当前章节顺序
- 章节内字符偏移或可恢复锚点
- 阅读方式
- 最近保存时间

### Bookmark

- 唯一 ID、书籍 ID、章节顺序
- 章节内位置、正文摘要、创建时间

### ReaderPreferences

- 默认主题
- 默认阅读方式
- 字号
- 行距

未读章节数按“尚未完成阅读的章节数”计算。新导入书籍默认全部未读；读者进入下一章后，上一章记为已读。若无法可靠判断章节，则整本书作为单章处理。

## 6. 导入与解析流程

1. 用户从设置页选择文件或文件夹。
2. 应用通过 Android Storage Access Framework 取得用户明确授权的 URI。
3. 校验扩展名、可读性与重复导入情况。
4. 将文件复制到应用私有目录；原始文件保持不变。
5. 从文件名自动识别书名和作者。优先识别“书名 - 作者”“书名_作者”等常见形式；无法识别作者时使用“未知作者”。
6. 后台解析章节和封面，持续更新导入状态。
7. 解析成功后写入 Room 并显示在书架；失败时清理未完成的应用副本并给出可理解的错误提示。

TXT 默认先尝试 UTF-8，再兼容 GB18030 等常见中文编码。章节识别支持“第十二章”“第12回”等常见标题；没有匹配时整本书作为单章。

EPUB 解析读取容器、OPF、阅读顺序、目录、XHTML 正文和内置封面。正文在展示前清理脚本和不安全标签，只保留阅读需要的文本及基础段落结构。

重复文件以内容指纹加文件大小判断。发现重复时不创建第二份书籍记录，而是提示用户该书已在书架中。

## 7. 阅读与进度

- 阅读器加载当前章节及前后相邻章节，避免一次性把整本书放入内存。
- 分页模式根据可用尺寸、字号、行距和正文重新排版；设置变化后尽量保持当前文字锚点。
- 滚动模式以章节为加载单位，在接近边界时预加载相邻章节。
- 进度在章节切换、应用进入后台、退出阅读页时保存；阅读过程中按节流方式定期保存。
- 主题和排版设置立即生效，并同步到默认偏好；单本书的阅读方式随进度保存。

## 8. 删除行为

删除操作必须显示书名并二次确认。确认后删除应用私有副本、解析缓存、数据库记录、阅读进度和书签；绝不删除或修改用户原始文件。删除失败时保留数据库记录并提示重试，避免出现书籍记录与文件状态不一致。

## 9. 异常处理

- 无法读取：提示文件权限或文件损坏，不创建书架记录。
- 不支持格式：明确提示第一版仅支持 TXT 与 EPUB。
- 编码识别失败：依次尝试 UTF-8 与 GB18030；如果内容仍包含大量不可解码字符，则停止导入并提示文件编码无法识别。
- EPUB 结构不完整：尽可能按 spine 顺序恢复；无法形成正文时判定导入失败。
- 空文件或空章节：拒绝导入并说明原因。
- 存储空间不足：在复制前后检查失败并清理临时文件。
- 应用被中断：导入先写临时文件，全部成功后再原子化转为正式书籍记录。

## 10. 测试与验收

### 自动测试

- 单元测试：文件名元数据识别、TXT 编码选择、章节切分、未读数计算、进度锚点换算。
- 数据测试：Room 的书籍、章节、书签和级联删除行为。
- ViewModel 测试：导入状态、删除确认、设置保存和阅读进度恢复。
- Compose UI 测试：书架信息层级、设置图标、三点菜单、设置页、阅读工具栏和三种主题。
- 设备测试：Storage Access Framework 文件与目录导入、应用后台恢复和配置变化。

### 第一版验收标准

- 可在 Android 8.0 及以上设备安装并启动。
- 能从系统文件选择器导入真实 TXT 与 EPUB，并在离线状态阅读。
- 关闭并重新打开应用后，书架、进度、偏好和书签仍然存在。
- 分页与滚动模式均能恢复到接近退出前的位置。
- 删除书籍后应用副本和相关数据消失，原始文件仍存在。
- 书架和阅读页在常见手机宽度下无文字遮挡、按钮重叠或无法点击的问题。

## 11. 实施顺序

1. 建立 Android 工程、主题、导航和数据模型。
2. 完成 Room、DataStore 与应用私有文件仓库。
3. 先实现 TXT 导入、章节解析和书架闭环。
4. 实现阅读器、进度、主题、字号、目录和书签。
5. 增加 EPUB 解析并复用同一阅读流程。
6. 完成设置页、文件夹扫描、删除与错误状态。
7. 进行真机/模拟器验收、性能修正与 APK 构建。
